# Schoenflies

/ˈʃøːnfliːs/

Determine and visualise molecular symmetry.

## Dependencies (Debian)

```
sudo apt install build-essential qt5-default libboost-all-dev libglm-dev
```

## Compilation (Debian)

```
$ cd build
$ cmake ..
$ make -j5
```
